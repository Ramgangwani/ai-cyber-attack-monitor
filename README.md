# AI-Based Intrusion Detection System

A beginner-friendly machine learning project for detecting suspicious network
traffic from flow-style CSV data.

The project trains a Random Forest model on labeled network-flow records and
then uses the saved model to classify new traffic as `normal` or `attack`.

## Project Structure

```text
data/                  CSV datasets live here
models/                Trained model files live here
src/ids/features.py    Feature preparation and validation
src/ids/sample_data.py Creates a demo dataset
src/ids/train.py       Trains and saves the ML model
src/ids/detect.py      Runs detection on new CSV traffic
src/ids/live_detect.py Captures live packets and runs real-time detection
tests/                 Unit tests
```

## Setup

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Quick Start

Train the IDS model with NSL-KDD:

```powershell
python -m src.ids.train
```

This reads `data/KDDTrain+.txt.zip`, preprocesses NSL-KDD categorical features,
converts all attack names into the binary `attack` class, trains a Random
Forest model, and saves it to `models/ids_model.joblib`.

Train with an explicit NSL-KDD file:

```powershell
python -m src.ids.train --data data/KDDTrain+.txt.zip --model models/ids_model.joblib
```

Detect attacks in a CSV file:

```powershell
python -m src.ids.detect --input data/network_traffic.csv --model models/ids_model.joblib
```

The older synthetic demo workflow is still available for quick experiments:

```powershell
python -m src.ids.sample_data --output data/network_traffic.csv
python -m src.ids.train --data data/network_traffic.csv --model models/demo_ids_model.joblib --format demo
```

Run live packet detection:

```powershell
python -m src.ids.live_detect --model models/ids_model.joblib
```

List available network interfaces:

```powershell
python -m src.ids.live_detect --list-interfaces
```

Run on a specific interface:

```powershell
python -m src.ids.live_detect --interface "Wi-Fi" --model models/ids_model.joblib
```

Live capture notes:

- On Windows, install Npcap if Scapy cannot capture packets.
- Run PowerShell or Command Prompt as Administrator for live packet sniffing.
- Live detections are saved into `data/ids_logs.sqlite3`, so the Flask dashboard
  history and reports can show alerts generated by packet capture.
- The live detector aggregates packets into flow-style features before passing
  them into the trained model.

## Android Simulator App

An Android Java client is available in `android-client/`. It sends safe
simulated NSL-KDD-style traffic records to the Flask IDS API. It does not create
real DoS traffic, perform real login attempts, or scan networks.

Start Flask for Android emulator access:

```powershell
python -m src.ids.web
```

Use this server URL in the emulator app:

```text
http://10.0.2.2:5000
```

For a physical Android phone on the same Wi-Fi, start Flask on all interfaces:

```powershell
python -m src.ids.web --host 0.0.0.0
```

Then use your laptop IP address in the app, for example:

```text
http://192.168.1.10:5000
```

Android app login:

```text
Username: admin
Password: rg@123
```

Open `android-client/` in Android Studio, run the app, tap `Login to Flask IDS`,
then send one of the safe patterns:

- DoS-like burst pattern
- Repeated login pattern
- Network scan pattern
- Normal traffic pattern

Each simulation is posted to `/api/predict`, stored in SQLite, and displayed in
the Flask dashboard history, charts, and reports.

## CSV Format

NSL-KDD training data is expected to use the standard KDDTrain+/KDDTest+
columns. Headerless 42-column and 43-column files are supported, including
zipped files such as `KDDTrain+.txt.zip`.

The synthetic demo format uses these columns:

```text
duration, protocol, src_bytes, dst_bytes, packets, errors, login_attempts, label
```

Detection input uses the same columns except `label` is optional.

## Notes

The main model now trains from NSL-KDD instead of synthetic demo traffic. For a
larger final project, you can also adapt the same preprocessing pattern for
UNSW-NB15 or CIC-IDS2017.
